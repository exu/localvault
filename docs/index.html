Secrets for your shell, safe around AI agents.

A small local vault for the command line. Unlock with a password, run commands with secrets injected, and never let the values land in a transcript. No server, no account.

Install View on GitHub

Why localvault

When an AI coding agent runs your commands, any secret it prints ends up in its context. localvault keeps values out of that path.

Output redaction

localvault run scrubs every stored value from stdout and stderr, replacing it with [REDACTED:NAME].

Not in ps

Secrets reach the command as environment variables, never as arguments.

Native unlock dialog

An agent asks, you see who and what, and you type the password in a real window. macOS and Linux (pinentry, zenity, kdialog).

Local and simple

One static binary, one encrypted file. XChaCha20-Poly1305 with an argon2id-derived key.

Install

macOS and Linux, amd64 and arm64.

Homebrew

brew install exu/tap/localvault

Install script

curl -fsSL https://raw.githubusercontent.com/exu/localvault/main/install.sh | sh

Verifies the SHA256 checksum and installs to ~/.local/bin. Set VERSION to pin a release or INSTALL_DIR to change the target.

From source (Go 1.27+)

git clone https://github.com/exu/localvault && cd localvault
make build
install -m 0755 dist/localvault ~/.local/bin/

Usage

Create a vault once, then store and use secrets.

localvault configure                 # create vault, set password
localvault unlock                    # start a 15m session
localvault set API_TOKEN=abc123      # store a secret
pbpaste | localvault set API_TOKEN=- # or from stdin, out of shell history
localvault list
localvault lock

Use a secret in a command. The value is injected, and scrubbed from the output.

localvault run 'curl -H "Authorization: Bearer $env[API_TOKEN]" https://example.com'
CommandWhat it does
configureCreate the vault, or add or replace an unlocker.
unlock [--ttl 15m]Authenticate and start a session.
set KEY=valStore secrets. KEY=- reads stdin.
get KEYPrint a raw value. Prefer run for agents.
run 'cmd $env[KEY]'Run a command with secrets injected and output redacted.
list, deleteList names, remove a secret.
status, lockShow or end the session.

If the vault is locked, get, set, list, delete and run unlock it themselves: a terminal prompt, or a dialog window when there is no terminal. --no-prompt makes them fail instead.

Security model

localvault protects secrets at rest and keeps them out of agent transcripts. It is deliberately simple.

At rest

A random key encrypts the vault. Each unlocker wraps its own copy, and the unlocker list is authenticated. The password unlocker uses argon2id (512 MiB, about 250 ms per guess).

While unlocked

A session file holds the key until the TTL ends. Malware running as you can read it, so keep the TTL short and run lock when done.

Redaction limits

Only literal values are matched, not base64 or other transforms. Values shorter than 4 characters are not redacted, and a warning names them.
